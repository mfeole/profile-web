# Bautismo de las creencias

Website for the project *Bautismo de las creencias* (in Spanish). Same setup as the profile page: a single static `index.html` (plain HTML, CSS, and a little JavaScript, no build step), ready for GitHub Pages.

The two project colors are dark red (`#8f1d2c`, with `#1a070b` as the page ground) and ivory (`#f4ecd8`). Dark red with ivory letters is the default theme; the sun button switches to the light theme (ivory ground, red letters).

Text in `[brackets]` is placeholder content still to be written.

## Preview

Open `index.html` in a browser, or serve the folder with `python3 -m http.server`.
